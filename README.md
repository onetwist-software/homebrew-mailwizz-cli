# homebrew-mailwizz-cli

Homebrew tap for [mailwizz-cli](https://github.com/onetwist-software/mailwizz-cli), a command line
client for the MailWizz REST API.

## Install

```
brew tap onetwist-software/mailwizz-cli
brew install --cask mailwizz-cli
```

The cask in this tap is generated and pushed automatically by GoReleaser on every tagged release of
mailwizz-cli. Do not edit files under `Casks/` by hand; they will be overwritten on the next release.
